# Бот и мини-приложение для MAX

Ищем людей на работу и даём им откликаться прямо в мессенджере. Для небольших компаний, у которых нет отдельного HR: пекарня, магазин, ферма, небольшая IT-контора.

Соискатель заполняет анкету, смотрит вакансии, откликается. Работодатель проверяется по ЕГРЮЛ/ЕГРИП и публикует вакансии. Пока отклик не приняли, телефоны скрыты. Если приняли — контакты уходят обеим сторонам.

Данные в `data.json`, фото в `miniapp/uploads`.

## Как запускать

Токен бота кладёте в `.env` (файл в git не коммитим). Шаблон — `.env.example`.

Одной командой, как просят на хакатоне:

```bash
cp .env.example .env
cp data.example.json data.json
docker compose up --build
```

Снаружи мини-приложение на порту 80 (nginx). Внутри Node сидит на 8080.

Остановить: `docker compose down`.

Без Docker, пока пишете код: `npm install` и `node bot.js`. Тогда адрес такой: `http://localhost:8080`.

## Что в .env

- `BOT_TOKEN` — без него бот не стартует
- `MINI_APP_URL` — для Docker локально `http://localhost`, для MAX нужен `https://домен`
- `MINIAPP_DEV_USER_ID` — только для localhost, под каким юзером открывать мини-приложение в браузере
- `ESIA_DEMO=true` — тестовый вход «Госуслуги», не промышленный ЕСИА
- `EGRUL_DEMO=false` — живая ФНС; `true` только если egrul.nalog.ru недоступен
- `NODE_TLS_REJECT_UNAUTHORIZED=0` — на Windows без этого MAX часто не открывается

Порты: 80 снаружи через nginx, 8080 внутри контейнера. Зависимости зафиксированы в `package-lock.json`.

## Что снаружи, в Docker не поднять

MAX (бот, фото, уведомления), ФНС, Госуслуги/ЕСИА. Без живого бота в MAX основной сценарий жюри не пройдёт.

`data.example.json` — тестовая пекарня и одна вакансия, это не выгрузка из госсистем.

## Как проверить

Два аккаунта MAX.

1. Соискатель: анкета → «Найти работу» → отклик.
2. Работодатель: компания + проверка → вакансия. В уведомлении «Принять» — тогда обоим приходят телефоны.
3. Работодатель: «Найти работников» → откликнуться на анкету. Соискатель принимает.
4. Раздел «Отклики» — входящие и свои.
5. Мини-приложение: тот же сценарий на `http://localhost` (Docker) или `:8080` без Docker.

## Ограничения

MAX не откроет мини-приложение с localhost из чата, нужен HTTPS. Ник бота после создания не меняется. Боевой ЕСИА пока не подключён, это написано в интерфейсе. Своего публичного API нет.
